# Data-Structure-in-C-programming
This Repository contains my complete journey of learning and implementing Data Structures Using C Programming.

The main idea behind this repository is to store all my code in a sequential and organized order, covering each Data Structure step by step. Every implementation represents a stage of my learning journey and helps me track how far I have progressed and how much I have improved over time.

I will continuously add implementations, practice problems, and important concepts related to Data Structures, starting from the fundamentals and gradually moving toward more advanced topics.
